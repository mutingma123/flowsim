FlowSim model builder prototype

Draw a small service network, set its durations, and copy the FlowSim script it writes. The script is ordinary FlowSim code to edit further, and running it is the final check of the model.

Not in this builder: customer types, schedules, finite buffers, abandonment, failures, priorities, and supply chains. Add them by editing the script.

Drag a node to move it. Drag from the dot on a node's right edge to another node to add a route. Two or more routes from one node make a branch, with a probability on each arrow. Select a node or an arrow to edit it, and press Delete to remove it.
